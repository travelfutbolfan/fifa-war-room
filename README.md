# FIFA Election War Room

A live map of who backs whom in the March 2027 FIFA presidential election: all 211 voting associations, a what-if tool, a timeline, and the rules explained.

Created by Danny Navarro, [@travelfutbolfan](https://www.instagram.com/travelfutbolfan/).

Static site: `index.html`, `war.js`, `war.css`, and data in `data/`. Pledges are public statements, not votes; the ballot is secret. Corrections with a source are welcome.
